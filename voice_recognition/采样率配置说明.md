## 🎵 采样率修改详解

### 修改后的代码支持两种采样率：

| 采样率 | 说明 | 优点 | 缺点 | 适用场景 |
|--------|------|------|------|----------|
| **16000Hz** | 电话音质 | 带宽小，识别快 | 音质一般 | 普通语音识别（推荐） |
| **44100Hz** | CD音质 | 音质好 | 带宽大，传输慢 | 高质量录音 |

### 已修改的3个位置：

#### ✅ 1. 全局配置（第24行）
```python
SAMPLE_RATE = 44100  # 改为你需要的采样率
```

#### ✅ 2. PyAudio音频流配置（第158行）
```python
stream = p.open(
    format=pyaudio.paInt16,
    channels=1,
    rate=SAMPLE_RATE,  # 使用配置的采样率
    input=True,
    frames_per_buffer=frames_per_buffer
)
```

**缓冲区大小自动计算**：
```python
# 44100Hz：frames_per_buffer = 2205 (约50ms)
# 16000Hz：frames_per_buffer = 800  (约50ms)
frames_per_buffer = int(SAMPLE_RATE * 0.05)
```

#### ✅ 3. 讯飞API数据格式（第187和203行）
```python
"format": f"audio/L16;rate={SAMPLE_RATE}"
```

## 🔧 如何切换采样率

### 方法1：修改配置变量（推荐）

直接修改第24行：
```python
# 使用 16kHz（推荐，节省流量）
SAMPLE_RATE = 16000

# 或使用 44.1kHz（高音质）
SAMPLE_RATE = 44100
```

### 方法2：检测麦克风自动设置

如果不确定麦克风支持什么采样率，可以添加检测代码：

```python
import pyaudio

def get_default_sample_rate():
    """自动检测麦克风支持的采样率"""
    p = pyaudio.PyAudio()
    
    # 尝试的采样率列表
    rates = [44100, 48000, 32000, 22050, 16000, 11025, 8000]
    
    for rate in rates:
        try:
            # 尝试打开音频流
            stream = p.open(
                format=pyaudio.paInt16,
                channels=1,
                rate=rate,
                input=True,
                frames_per_buffer=1024
            )
            stream.close()
            print(f"✅ 麦克风支持采样率: {rate}Hz")
            p.terminate()
            return rate
        except:
            continue
    
    p.terminate()
    return 16000  # 默认返回16kHz

# 使用
SAMPLE_RATE = get_default_sample_rate()
```

## 📊 采样率对比

### 数据量对比

假设录音1秒钟：

| 采样率 | 每秒数据量 | 50ms数据包大小 | 网络带宽需求 |
|--------|-----------|---------------|-------------|
| 8000Hz | 16KB | 800字节 | 低 |
| 16000Hz | 32KB | 1.6KB | 中 |
| 44100Hz | 88.2KB | 4.41KB | 高 |

**计算公式**：
```
数据量 = 采样率 × 采样位数 ÷ 8
       = 44100 × 16 ÷ 8
       = 88200 字节/秒
       ≈ 86 KB/秒
```

### 识别准确度对比

根据科大讯飞官方文档：
- **16kHz**：识别准确率 **95%+**（推荐）
- **44.1kHz**：识别准确率 **95%+**（无明显提升）

**结论**：对于语音识别，16kHz完全够用！

import pyaudio

def test_microphone():
    p = pyaudio.PyAudio()
    
    print("=" * 50)

    print("\n" + "=" * 50)
    print("测试采样率兼容性...")
    print("=" * 50)
    
    # 测试常用采样率
    test_rates = [8000, 16000, 22050, 44100, 48000]
    for rate in test_rates:
        try:
            stream = p.open(
                format=pyaudio.paInt16,

                rate=rate,

            print(f"✅ {rate}Hz - 支持")

## ❓ 常见问题

### Q1: 为什么选择50ms作为缓冲区时间？
**A**: 50ms是语音识别的最佳平衡点：
- 太小（<20ms）：CPU占用高，网络开销大
- 太大（>100ms）：延迟高，实时性差
- 50ms：延迟低，流畅度好

### Q2: 44100Hz和16000Hz识别率有差别吗？
**A**: **几乎没有差别**。语音识别主要关注语音频率（300-3400Hz），16kHz采样率完全覆盖这个范围。

### Q3: 能用48000Hz吗？
**A**: 可以！讯飞支持48000Hz，修改方式相同：
```python
SAMPLE_RATE = 48000
```

### Q4: 修改采样率后识别出错怎么办？
**A**: 检查：
1. 麦克风是否支持该采样率
2. 网络是否稳定（高采样率需要更好的网络）
3. 讯飞API配额是否充足
