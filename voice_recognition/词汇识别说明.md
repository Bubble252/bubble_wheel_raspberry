## 🔍 识别原理解析

### 当前代码逻辑（已优化）

```python
# 定义关键词列表
turn_on_keywords = ["开机", "开启", "启动", "打开", "凯机"]
turn_off_keywords = ["关机", "关闭", "停止", "光机"]

# 模糊匹配：只要识别文本包含任何一个关键词
if any(keyword in text for keyword in turn_on_keywords):
    self.turn_on()
elif any(keyword in text for keyword in turn_off_keywords):
    self.turn_off()
```

### 工作流程

```
用户说话："请帮我开机"
    ↓
科大讯飞识别："请帮我开机"
    ↓
检查是否包含开机关键词：
  - "开机" in "请帮我开机" ✅ 匹配！
    ↓
执行开机操作 ✅
```

## 🛠️ 自定义更多关键词

### 如何添加更多同义词？

编辑 `voice_recognition_simple.py` 第114-115行：

```python

turn_on_keywords = [
    "开机", "开启", "启动", "打开",  # 标准词
    "凯机", "开鸡",                   # 同音词
    "上电", "通电", "运行",           # 技术词
    "给我来",                         # 口语
]

# 关机关键词（可以继续添加）
turn_off_keywords = [
    "关机", "关闭", "停止",           # 标准词
    "光机", "官机",                   # 同音词
    "断电", "切断", "结束",           # 技术词
    "睡觉",                          # 口语
]
```
