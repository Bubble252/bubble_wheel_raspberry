## 📝 关于那些警告信息

### 1️⃣ ALSA 警告（可以忽略）

```
ALSA lib pcm.c:2642:(snd_pcm_open_noupdate) Unknown PCM cards.pcm.rear
ALSA lib pcm_route.c:869:(find_matching_chmap) Found no matching channel map
...
```

**这是什么？**
- Linux音频系统（ALSA）的正常警告
- 表示你的声卡不支持某些环绕声配置
- **完全不影响使用**，可以安全忽略

**如何隐藏这些警告？**（可选）

方法1：重定向stderr
```bash
python3 voice_recognition_simple.py 2>/dev/null
```

方法2：创建ALSA配置（不推荐，可能影响其他程序）

---

### 2️⃣ WebSocket 超时断开

```
🔌 WebSocket连接已关闭
reason=server read msg timeout
```

**为什么会断开？**
- 你说完"开机"后，长时间没有说话
- 讯飞服务器检测到2秒静音后自动断句
- 然后等待超时，主动断开连接（这是正常的）

**解决方法：**

**方法A：重新运行（推荐）**
```bash
python3 voice_recognition_simple.py
```

**方法B：调整静音检测时间**

编辑 `voice_recognition_simple.py` 第199行：
```python
"vad_eos": 5000  # 改为5000（5秒）或10000（10秒）
```

## 💡 使用技巧

### ✅ 技巧1：快速连续识别

```bash
# 启动后，快速说：
"开机"（等1秒）"关机"（等1秒）"开机"...
```

每次指令之间间隔**少于2秒**，就不会断开连接。

### ✅ 技巧2：完整句子

系统支持模糊匹配，可以说：
- "请开机"
- "帮我开机"
- "开机吧"
- "关闭机器"
- "关机"

只要包含"开机"或"关机"关键词即可。

### ✅ 技巧3：调整采样率优化

当前你使用的是：
```python
SAMPLE_RATE = 44100  # CD音质
```

建议改为：
```python
SAMPLE_RATE = 16000  # 语音识别推荐
```

**优点：**
- 网络流量减少2/3
- 延迟更低
- 识别准确率相同
