## 🔧 常见问题

### ❌ 问题1：`ModuleNotFoundError: No module named 'pyaudio'`

**解决：**
```bash
sudo apt install portaudio19-dev python3-dev
pip3 install pyaudio
```

### ❌ 问题2：`ModuleNotFoundError: No module named 'websocket'`

**解决：**
```bash
pip3 install websocket-client
```

注意：是 `websocket-client` 不是 `websocket`！

### ❌ 问题3：`[Errno -9997] Invalid sample rate`

**原因：** 麦克风不支持你设置的采样率

**解决：**
1. 运行 `python3 check_microphone.py` 检测支持的采样率
2. 修改 `SAMPLE_RATE` 为支持的值（推荐16000）

### ❌ 问题4：`OSError: [Errno -9996] Invalid input device`

**原因：** 找不到麦克风设备

**解决：**
```bash
# 检查麦克风设备
arecord -l

# 如果是USB麦克风，尝试重新插拔
# 然后运行检测脚本
python3 check_microphone.py
```

### ❌ 问题5：识别不准确

**解决：**
1. 确保麦克风权限正常
2. 说话清晰，距离麦克风10-30cm
3. 减少环境噪音
4. 调整 `vad_eos` 参数（第199行）：
   ```python
   "vad_eos": 2000  # 增加到3000或5000试试
   ```

### ❌ 问题6：WebSocket连接错误

**可能原因：**
- 网络问题
- API密钥错误
- API配额用完

**检查：**
```bash
# 测试网络连接
ping iat-api.xfyun.cn

# 检查API配额
# 登录 https://console.xfyun.cn/ 查看剩余调用次数
```

## 📊 采样率选择建议

| 采样率 | 优点 | 缺点 | 场景 | 推荐度 |
|--------|------|------|------|--------|
| **16000** | 识别准确、流量小、延迟低 | 音质一般 | 语音识别 | ⭐⭐⭐⭐⭐ |
| **44100** | 音质好 | 流量大、延迟稍高 | 高质量录音 | ⭐⭐⭐ |
| **8000** | 流量最小 | 识别率稍低 | 低带宽环境 | ⭐⭐ |

**推荐：使用 16000 Hz**
- 语音识别准确率与44100几乎相同
- 网络流量只有44100的1/3
- 延迟更低，响应更快
