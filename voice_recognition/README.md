# 基于语音识别的电扇开关系统

#### 介绍
系统使用科大讯飞语音听写WebAPI实现语音识别功能，通过Websocket协议与讯飞服务器建立长连接，实时传输用户语音数据。用户的语音指令由麦克风采集并编码成音频流，实时发送至讯飞平台。服务器返回文本格式的识别结果后，系统提取其中的关键指令词，转变为控制命令，以此控制风扇开关。

#### 软件架构
软件架构说明
- 操作系统：Windows11
- 驱动环境：Python3.8
- 驱动支持：CH340串口驱动
- 语音识别系统：科大讯飞语音听写平台


#### 配置教程

1.  科大讯飞语音识别本地部署
本系统借助科大讯飞语音听写平台实现语音实时识别。进入该平台完成账号注册，选择智能语音条目下的实时语音听写服务，即可在“免费试用”入口获得Websocket服务接口认证信息，在“技术文档”的入口获取语音听写流式demo文件。

2.  软件准备
    - 安装serial
        在Powershell中安装serial，命令为：
        `pip install serial`
    - 安装modbus_tk
        在Powershell中安装serial，命令为：
        `pip install modbus_tk`
    - 下载CH430驱动并安装
        下载网址为：
        > http://www.wch.cn/products/CH430.html
        
3.  硬件准备
    - 电线焊接
        将风扇的USB线截断，并使用剥线钳将其外层绝缘皮去除，使得红色电源线与黑色电源线裸露。再分别对两条杜邦线截断、去除外层绝缘皮，将杜邦线与风扇USB线焊接，使得电线延长。
    - 接线组装
        根据C2S0301模块的用户手册，可以得知模块每个接线端子的含义如下。
![输入图片说明](https://foruda.gitee.com/images/1747876268743972695/a3c985d6_14430626.png "图片1.png")
        因此得到接线设计图如下，按照设计图完成接线组装。
    ![输入图片说明](https://foruda.gitee.com/images/1747876283806346012/c765bf2e_14430626.png "图片2.png")
    - 测试模块连接
        将USB转485模块连接电脑对设备进行供电，打开“设备管理器”找到模块所对应的USB端口。
        在官网下载C2S0301 对应的“上位机配置工具”，以管理员权限运行，点击连接模块后，在模块型号和模块名称处显示设备型号及名称，说明连接成功。

4. 代码实现详见main.py文件。
