# 简化版语音识别使用说明

## 📝 简介

这是一个**纯语音识别**版本，只识别"开机"和"关机"指令，**不需要继电器硬件**。
适用于：
- 测试语音识别功能
- 学习语音识别原理
- 作为其他应用的基础（比如控制软件、游戏、智能家居模拟器等）

---

## 🚀 快速开始

### 1. 安装依赖

```bash
# Ubuntu 20.04
sudo apt install portaudio19-dev python3-dev
pip3 install websocket-client pyaudio

# 或者 Windows
pip install websocket-client pyaudio
```

### 2. 配置API密钥

编辑 `voice_recognition_simple.py` 文件，修改第12-14行：

```python
APPID = "你的APPID"
APIKey = "你的APIKey"
APISecret = "你的APISecret"
```

**获取方式：**
1. 访问 https://www.xfyun.cn/
2. 注册并登录
3. 控制台 → 创建应用 → 选择"语音听写"
4. 复制 APPID、API Key、API Secret

### 3. 运行程序

```bash
python3 voice_recognition_simple.py
```

### 4. 测试

对着麦克风说：
- **"开机"** → 系统输出：✅ 开机成功！
- **"关机"** → 系统输出：✅ 关机成功！

也支持说：
- "帮我开机"
- "请关机"
- "开机吧"
等包含关键词的自然语句

## 🎯 核心功能

### 识别逻辑

```python
def on_message(self, ws, message):
    # 提取识别文本
    text = "识别到的文字"
    
    # 判断指令
    if "开机" in text:
        self.turn_on()
    elif "关机" in text:
        self.turn_off()
```

### 场景1：语音控制视频播放

```python
import pyautogui

class VideoController(SimpleVoiceRecognition):
```

### 场景2：语音启动应用

```python
import subprocess

def on_message(self, ws, message):
    text = "识别到的文字"
    
    apps = {
        "浏览器": "firefox",
        "终端": "gnome-terminal",
        "记事本": "gedit",
        "音乐": "rhythmbox"
    }
    
    for keyword, app in apps.items():
        if keyword in text:
            subprocess.Popen([app])
            print(f"✅ 已启动{keyword}")
```

## 🔍 与原版的区别

| 功能 | 原版 (main.py) | 简化版 |
|------|----------------|--------|
| **硬件依赖** | 需要继电器+USB转485 | ❌ 不需要 |
| **Python包** | serial, modbus_tk, pyaudio, websocket | 只需 pyaudio, websocket |
| **识别指令** | "开风扇"/"关风扇" | "开机"/"关机" |
| **输出** | 控制继电器硬件 | 只打印提示信息 |
| **适用场景** | 硬件控制 | 软件控制/测试/学习 |
| **复杂度** | 较高（涉及Modbus协议） | 简单（纯软件） |

## ❓ 常见问题

### Q1: 识别不准确怎么办？
```python
# 调整静音检测时间（默认2000ms）
"business": {
    "vad_eos": 2000,  # 改为1000或3000试试
}

# 或者增加多个关键词
if any(kw in text for kw in ["开机", "开启", "打开", "启动"]):
    self.turn_on()
```

### Q2: 如何支持英文识别？
```python
"business": {
    "language": "en_us",  # 英文
    "domain": "iat",
    "accent": "mandarin",
}

# 识别逻辑
if "turn on" in text.lower():
    self.turn_on()
```

### Q3: 能离线使用吗？
不能，科大讯飞API需要联网。如需离线识别，可以使用：
- PocketSphinx（离线，准确率较低）
- Vosk（离线，开源）
- Whisper（OpenAI，可本地运行）

### Q4: 如何记录识别的所有文本？
```python
def on_message(self, ws, message):
    text = "识别到的文字"
    
    # 保存到文件
    with open('recognition_log.txt', 'a', encoding='utf-8') as f:
        f.write(f"{datetime.datetime.now()}: {text}\n")
```
